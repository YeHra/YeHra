# Data Analytics Portfolio

Hi, I'm YeHra — this is a collection of data analytics projects covering the full pipeline: data cleaning, exploratory analysis, unit economics, A/B testing, SQL/NoSQL application development, and BI dashboarding.

## 📂 Projects

### [CRM Data Analysis: Marketing & Sales Efficiency](https://github.com/YeHra/crm-unit-economics-ab-testing)
End-to-end analysis of CRM data for an online coding school — data cleaning (Python/pandas), exploratory analysis, unit economics per product, and A/B test design. Includes a Power BI dashboard.

`Python` · `pandas` · `plotly` · `geopandas` · `Power BI` · `Excel`

### [Film Database Search CLI: MySQL + MongoDB Atlas](https://github.com/YeHra/film-catalog-search-mysql-mongodb)
An interactive CLI application searching a film catalog (MySQL/Sakila) with every query logged to MongoDB Atlas for search analytics — demonstrating a layered architecture combining relational and non-relational databases.

`Python` · `PyMySQL` · `PyMongo` · `MySQL` · `MongoDB Atlas`

### [Dashboards Portfolio](https://github.com/YeHra/dashboards-portfolio)
BI dashboards in Tableau (published live) and Power BI, covering flight-delay analytics, retail order operations, and e-commerce performance across sales, logistics, payments, and reviews.

`Tableau` · `Power BI`

## 🛠 Overall Tech Stack

**Languages & Libraries:** Python (pandas, numpy, plotly, geopandas, folium), SQL
**Databases:** MySQL, MongoDB
**BI Tools:** Power BI, Tableau
**Other:** Excel, Google Colab, Git/GitHub
