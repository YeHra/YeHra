# Data-Analytics-Portfolio

Hallo, ich bin YeHra — hier findest du eine Sammlung von Data-Analytics-Projekten, die die gesamte Pipeline abdecken: Datenbereinigung, explorative Analyse, Unit Economics, A/B-Testing, SQL-/NoSQL-Anwendungsentwicklung und BI-Dashboarding.

## 📂 Projekte

### [CRM-Datenanalyse: Marketing- und Vertriebseffizienz](https://github.com/YeHra/crm-unit-economics-ab-testing)

End-to-End-Analyse von CRM-Daten einer Online-Programmierschule — Datenbereinigung (Python/pandas), explorative Analyse, Unit Economics pro Produkt und Konzeption eines A/B-Tests. Inklusive Power-BI-Dashboard.

`Python` · `pandas` · `plotly` · `geopandas` · `Power BI` · `Excel`

### [Filmdatenbank-Suche CLI: MySQL + MongoDB Atlas](https://github.com/YeHra/film-catalog-search-mysql-mongodb)

Eine interaktive CLI-Anwendung zur Suche in einem Filmkatalog (MySQL/Sakila), bei der jede Suchanfrage zu Analysezwecken in MongoDB Atlas protokolliert wird. Sie demonstriert eine mehrschichtige Architektur, die relationale und nicht relationale Datenbanken kombiniert.

`Python` · `PyMySQL` · `PyMongo` · `MySQL` · `MongoDB Atlas`

### [Dashboards-Portfolio](https://github.com/YeHra/dashboards-portfolio)

BI-Dashboards in Tableau (live veröffentlicht) und Power BI — mit Analysen zu Flugverspätungen, der Bestellabwicklung im Einzelhandel und der E-Commerce-Performance in den Bereichen Vertrieb, Logistik, Zahlungen und Bewertungen.

`Tableau` · `Power BI`

## 🛠 Gesamter Tech-Stack

**Sprachen & Bibliotheken:** Python (pandas, numpy, plotly, geopandas, folium), SQL
**Datenbanken:** MySQL, MongoDB
**BI-Tools:** Power BI, Tableau
**Weitere:** Excel, Google Colab, Git/GitHub

## 📌 Hinweis

Einige Projekte in diesem Portfolio wurden im Rahmen eines Data-Analytics-Kurses mit Feedback der Kursleitung erstellt. Projektspezifische Informationen, Datenquellen und Hinweise zur KI-gestützten Arbeitsweise findest du in den jeweiligen Repository-READMEs.
